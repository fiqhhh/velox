Cara Install

01
⬇️ Download & Extract ZIP
Klik tombol Download Extension di atas. Setelah selesai download, klik kanan file ZIP → Extract All (atau unzip). Kamu akan dapat folder bernama velox-extension.

Jangan hapus foldernya — extension ini harus tetap ada di komputer selama dipakai.
02
🔧 Buka Halaman Extensions Chrome
Buka Chrome, klik address bar, ketik lalu tekan Enter:
chrome://extensions📋 salin

Setelah halaman terbuka, aktifkan Developer Mode — togglenya ada di pojok kanan atas. Kalau sudah, akan muncul tiga tombol baru di kiri atas.
03
📂 Load Extension
Klik tombol "Load unpacked". Akan muncul dialog pilih folder.

Cari dan pilih folder velox-extension yang tadi kamu extract. Klik Select Folder.

✅ Kalau berhasil, kartu Velox akan muncul di halaman itu, dan icon 🎫 muncul di toolbar Chrome kanan atas.
04
⚙️ Setting & Jalankan
Klik icon 🎫 di toolbar → isi data diri di tab Config → pilih tipe tiket di tab Tiket → atur kecepatan di tab Lanjutan.

Klik 💾 Simpan Config → klik ▶ Jalankan Bot.

Bot otomatis isi form dan pilih tiket. Saat CAPTCHA muncul → selesaikan sendiri, setelah itu tiket berhasil didapat! 🎉

FAQ

Apakah extension ini aman? ▼
Iya. Extension ini hanya berjalan di halaman target site. Semua data (nama, email, dll) disimpan lokal di browser kamu, tidak dikirim ke mana pun.
Kenapa CAPTCHA tetap harus manual? ▼
CAPTCHA memang dirancang agar tidak bisa diotomasi — itulah tujuannya. Bot ini menangani semua bagian yang membutuhkan kecepatan (isi form, pilih tiket, centang syarat), kamu hanya perlu solve CAPTCHA di akhir.
Bisa di browser selain Chrome? ▼
Bisa! Kompatibel dengan Microsoft Edge, Brave, dan Opera. Cara installnya sama persis. Firefox tidak support karena perbedaan sistem extension.
Cara install di Android? ▼
Pakai Kiwi Browser (gratis di Play Store) — satu-satunya browser Android yang support Chrome extension.

1. Download file CRX (tombol hijau di atas) ke HP
2. Install Kiwi Browser dari Play Store
3. Buka Kiwi → ketik kiwi://extensions di address bar
4. Aktifkan Developer Mode
5. Klik "+ (from .zip/.crx/.user.js)" → pilih file CRX
6. ✅ Extension aktif! Setting sama seperti di desktop.
Extension hilang setelah Chrome restart? ▼
Kadang Chrome meminta konfirmasi untuk tetap mengaktifkan extension yang di-load manual. Kalau muncul notif "Disable developer mode extensions", klik Keep atau Cancel (jangan klik Disable).
Cara update ke versi baru? ▼
Download ZIP versi baru → extract → timpa folder lama → di chrome://extensions klik ikon reload 🔄 di kartu Velox.
