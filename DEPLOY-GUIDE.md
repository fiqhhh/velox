# 🚀 Deploy Velox ke GitHub Pages
*Sudah punya akun GitHub? Selesai dalam ~5 menit.*

---

## Step 1 — Buat Repo Baru

Buka: **https://github.com/new**

Isi:
- **Repository name**: `velox` (bebas, ini yang jadi bagian URL)
- Visibility: **Public** ← wajib, biar GitHub Pages gratis
- ✅ Centang **"Add a README file"**

Klik **"Create repository"**

---

## Step 2 — Upload 2 File Ini

Di halaman repo → klik **"Add file"** → **"Upload files"**

Upload keduanya sekaligus:
- `index.html`
- `velox-extension.zip`

Scroll bawah → klik **"Commit changes"**

---

## Step 3 — Aktifkan GitHub Pages

**Settings** (tab atas) → sidebar kiri klik **Pages**

Di bagian **Source**:
- Branch: **`main`**
- Folder: **`/ (root)`**

Klik **Save** → tunggu ~2 menit

---

## Step 4 — Link Kamu Jadi:

```
https://USERNAME.github.io/velox
```

Ganti `USERNAME` dengan username GitHub kamu.

**Share link itu — selesai! 🎉**

---

### Cara update versi baru nanti:
Upload ulang `velox-extension.zip` (nama sama) → Commit → otomatis update.

### Mau link lebih pendek?
Pakai **https://s.id** (gratis, buatan lokal)
